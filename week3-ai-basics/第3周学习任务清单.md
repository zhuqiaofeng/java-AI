### ② 下午 45~60 分钟：Python 极简语法（只学够用的）

你已有 Java 基础，Python 只需要补这几个差异点：

| 对比项 | Java | Python |
|---|---|---|
| 变量 | `String s = "a";` | `s = "a"`（无类型声明） |
| 缩进 | 大括号 `{}` | **缩进即代码块**（4 空格） |
| 字符串 | 双引号 | 单/双引号都行；`f"{name} 你好"` 是模板字符串 |
| 字典 | `Map<String,Object>` | `{"key": "value"}`，用 `d["key"]` 取值 |
| 列表 | `List<T>` | `[1, 2, 3]`，切片 `arr[0:2]` |
| 空值 | `null` | `None` |
| 函数 | `public int f(int a)` | `def f(a):` |
| 循环 | `for (int i=0;i<n;i++)` | `for i in range(n):` / `for x in list:` |
| 异常 | try/catch | `try/except Exception as e:` |
| 包管理 | Maven `pom.xml` | `pip` + `requirements.txt` |
| 虚拟环境 | 无对应 | `python -m venv .venv` |
| JSON | Jackson | 内置 `json` 模块 |
| 打印调试 | System.out.println | `print(x)` |

再看一眼 `python-lab` 里任意一个脚本，能说出每一行在干嘛即可。

## 八、常见报错速查

| 现象 | 原因 | 解决 |
|---|---|---|
| `401 Unauthorized` / `InvalidApiKey` | Key 错、过期、带了多余空格 | 重新复制，检查环境变量是否有引号/换行 |
| `404 model not found` | 模型名写错或该地域不支持 | 去控制台「模型列表」核对准确 model id |
| `429 Too Many Requests` | 触发限流/QPS 上限 | 降并发、加重试（指数退避） |
| `400 invalid_request_error` | 参数不合法，如 temperature 超范围、messages 为空 | 打印 payload 逐字段比对文档 |
| `insufficient_quota` / 欠费 | 免费额度用完 | 控制台看余量，或换 DeepSeek |
| 流式没有逐字效果 | 客户端一次性读完 / 代理缓冲 | 确认 `stream=True` 且逐行 `iter_lines`；Nginx 关 buffering |
| 中文乱码 | 未指定编码 | `resp.encoding = "utf-8"` |
| `python` 命令不存在 | 未安装或未加 PATH | 运行 `00-安装Python.cmd`（装到 D 盘） |
| `ModuleNotFoundError: requests` | 依赖未装 | `python -m pip install -r requirements.txt` |
